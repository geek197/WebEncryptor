# WebEncryptor

A single-file, client-side encryption and decryption tool that runs entirely in your browser using the Web Crypto API. No data is ever transmitted to a server.

## Features

- **AES-GCM encryption/decryption** with 256-bit keys and 12-byte random IVs
- **PBKDF2 key derivation** using HMAC-SHA-256 with adaptive iteration benchmarking (~3s target)
- **Standalone decryptor export** — generate a self-contained HTML file with embedded ciphertext to share with recipients
- **Zero dependencies** — a single `index.html` file, no build step, no server required
- **100% client-side** — all cryptographic operations run locally in the browser

## Usage

Open `index.html` in any modern browser (Chrome, Firefox, Edge, Safari).

### Encrypting

1. Toggle to **Encrypt** mode
2. Enter a password
3. Enter the plaintext
4. Click **Encrypt** to get Base64-encoded ciphertext
5. Optionally download a standalone decryptor HTML file

### Decrypting

1. Toggle to **Decrypt** mode
2. Enter the password
3. Paste the Base64 ciphertext (JSON format)
4. Click **Decrypt** to recover the plaintext

Or open a standalone `encrypted-message.html` file generated by the tool.

## Ciphertext Format

Encrypted output is a JSON object containing:

```json
{
  "s": "<base64 salt>",
  "i": "<base64 IV>",
  "n": <iteration count>,
  "d": "<base64 ciphertext>"
}
```

## Cryptographic Details

| Property | Value |
|---|---|
| Algorithm | AES-GCM |
| Key size | 256 bits |
| IV size | 12 bytes (random per encryption) |
| Salt size | 16 bytes (random per encryption) |
| KDF | PBKDF2 with HMAC-SHA-256 |
| Iterations | Adaptive, benchmarked to ~3s per device |

## Browser Support

Requires the [Web Crypto API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Crypto_API), available in all modern browsers.
